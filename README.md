# VISMAYA M J – Portfolio

This is a static portfolio website.

## Publish it for a public URL (free)
1. Create a GitHub repository named `vismaya-portfolio`.
2. Upload `index.html` and this README to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will publish a URL similar to `https://YOUR-USERNAME.github.io/vismaya-portfolio/`.

Before publishing:
- Add `Vismaya_MJ_Observability_Resume.pdf` to this folder if you want the resume link on the site to work.
- Confirm the job title and employment dates match your official records.
- Add only public, non-confidential project details. Do not publish TCS internal screenshots, source code, customer names or data.
- Add a GitHub profile URL if you want it shown.
